Business rules, recovered from COBOL.

RuleForge reads legacy COBOL programs and writes out the business rules inside them as plain-English statements, so teams can modernize mainframe systems without guessing what the old code does.

View on GitHub contact@ruleforge.me

Open source, early-stage, and in active development.

COBOL input (illustrative example)

IF ACCT-TYPE = 'S'
   AND ACCT-BALANCE < MIN-BALANCE
      COMPUTE MONTHLY-FEE = 12.50
END-IF.

Extracted rule

Savings accounts with a balance below the minimum balance are charged a monthly fee of 12.50.

Each rule points back to the lines it came from.

How it works

The analysis runs on your own machine. Your source code is not sent to an outside service.

  1. Parse

    RuleForge reads the COBOL source and splits it into paragraphs and decision logic.

  2. Extract

    A language model running locally through Ollama turns each block of logic into a candidate rule.

  3. Review

    You get a list of plain-English rules, each linked to its source lines, ready for review.
